# Дорожка

Мобильное веб-приложение для интервальных тренировок на беговой дорожке. Работает как устанавливаемое PWA, хранит данные на устройстве и умеет управлять совместимой дорожкой через Web Bluetooth.

## Возможности

- готовые программы тренировок и редактор собственных программ;
- автоматическая смена скорости и наклона между этапами;
- таймер этапа, время с начала тренировки и пройденное расстояние;
- подключение по стандартному Bluetooth-профилю FTMS;
- текущий пульс с совместимых часов и средний пульс в истории тренировок;
- статистика расстояния и подробности тренировок по дням;
- резервное копирование тренировок, истории и настроек;
- офлайн-режим и выбор системного, светлого или тёмного оформления.

## Запуск

Проект не требует сборки и внешних JavaScript-зависимостей. Запустите в его каталоге любой статический HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`. Для работы Bluetooth на телефоне приложение должно быть размещено по HTTPS.

## Подключение дорожки

1. Полностью закройте FitShow или другое приложение, которое может удерживать Bluetooth-соединение.
2. Включите дорожку, Bluetooth и геолокацию на телефоне.
3. Откройте приложение в Chrome/Chromium на Android.
4. Нажмите «Подключить дорожку» и выберите устройство.

Приложение использует стандартный сервис Fitness Machine Service (`0x1826`) и характеристики FTMS Control Point и Treadmill Data. Дорожки с закрытым или фирменным протоколом могут быть несовместимы.

При запуске тренировки приложение сначала отправляет дорожке команду старта. Оно ждёт, пока лента действительно начнёт двигаться на минимальной скорости, и только затем задаёт скорость и наклон первого этапа. Если через четыре секунды скорость не начала расти, команда скорости отправляется повторно; в журнале появится сообщение «скорость не выросла — повторяю».

Всегда используйте страховочный ключ. При потере Bluetooth-связи дорожка может продолжить движение с последними заданными параметрами — остановите её физической кнопкой или ключом.

## Подключение часов

Приложение читает стандартный сервис Heart Rate (`0x180D`) и характеристику Heart Rate Measurement (`0x2A37`). На часах должен быть запущен режим, в котором они передают пульс по Bluetooth, например тренировка «Беговая дорожка».

При первом использовании нажмите «Подключить часы» и выберите часы в системном окне. Браузер требует это действие для выдачи разрешения. После первого успешного подключения приложение запоминает устройство и при следующих запусках пытается подключиться автоматически. Кнопка остаётся доступной для ручного подключения и отключения.

Текущий пульс показывается на главном экране. Во время запущенной тренировки показания накапливаются, а средний пульс сохраняется в истории и отображается в статистике и подробностях выбранного дня.

## Данные

Тренировки, настройки и история хранятся только в `localStorage` текущего браузера. Сервер и учётная запись не используются. Перед очисткой данных браузера создайте резервную копию в разделе «Настройки».

## Структура

- `index.html` — интерфейс, стили, таймер, статистика и Bluetooth-логика;
- `sw.js` — кеширование файлов для офлайн-работы;
- `manifest.webmanifest` — параметры установки PWA;
- `icon-192.png`, `icon-512.png` — иконки приложения.

## Ограничения браузера

- Web Bluetooth поддерживается не всеми браузерами; основной сценарий — Chrome/Chromium на Android.
- Автоматическое переподключение ранее разрешённых часов требует поддержки `navigator.bluetooth.getDevices()` браузером.
- Браузер может останавливать JavaScript в фоне. Во время тренировки приложение запрашивает Screen Wake Lock, но экран лучше не блокировать вручную.
- Bluetooth требует HTTPS, кроме локального адреса `localhost`.
